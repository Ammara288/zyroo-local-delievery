# Zyroo Local Delivery - Frontend MVP

A simple and modern frontend prototype for a Local Delivery & Logistics Management Platform. Built with React and React Router, using mock data (no backend required).

## 🚀 Technologies Used

- React (v19)
- React Router DOM (v7)
- Vite
- CSS (inline styling)
- Git & GitHub

## ✨ Features

- **Home Page** — Landing page with hero section, 3 features, and CTA
- **Dashboard** — Business stats (Total, Pending, In Delivery, Completed orders)
- **Orders Page** — List of all delivery orders with filter buttons
- **Order Details** — Detailed view with delivery timeline
- **Customer Tracking** — Live tracking page with route visualization
- **Responsive Design** — Works perfectly on desktop, tablet, and mobile
